# เว็บบันทึกรายรับรายจ่ายธุรกิจ

เว็บเวอร์ชันแรกสำหรับเจ้าของธุรกิจที่ต้องการบันทึกรายรับรายจ่ายแบบง่าย รองรับหลายธุรกิจ โปรเจกต์ แนบสลิป และ export CSV

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิดเว็บที่ `http://localhost:5173`

เมื่อสมัครสมาชิกครั้งแรก ระบบจะสร้างธุรกิจเริ่มต้นให้ 2 ธุรกิจ:

- Solar Cell
- รีโนเวทบ้านมือสอง

ข้อมูลถูกเก็บใน SQLite ที่ `data/app.sqlite` และสลิปถูกเก็บใน `data/uploads`

## รันแบบ production ในเครื่อง

```bash
npm run build
JWT_SECRET="เปลี่ยนเป็นรหัสสุ่มยาวๆ" NODE_ENV=production PORT=8080 npm start
```

ถ้าจะเปิดออนไลน์จริง ให้ดู [DEPLOY.md](./DEPLOY.md)
